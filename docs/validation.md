## 单实例与离线修复

应用先获取同一 Windows 用户共用的实例锁，再选择数据目录。重复启动会退出启动请求并恢复已有窗口；指定另一数据目录不会初始化第二个应用。桌面验收检查了两次重复启动，实际安装版也核对了不同数据目录的重复启动。

未登录时，朋友圈发布后台不会对空账号计算哈希。同步后台异常会被捕获，暂停对应功能并显示原因。离线验收等待两轮后台检查，未出现反复弹出的主进程错误。

## 验证边界

真实模型、搜索与生图测试确实发出了 API 请求。微信消息、联系人、朋友圈读写及服务器回执由隔离的模拟传输提供：**真实微信消息 0 条，群通知 0 条**。
